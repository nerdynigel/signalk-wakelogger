# Wake Logger for Signal K 0.2.0-beta.10

Release candidate: 11 October 2026.

## Keep navigation visible during course problems

The Race tab now keeps your live wind, boat speed, heading and VMG visible when a course cannot activate. With a cached course, it also shows the next mark and its bearing and distance. Missing offline forecasts or chart preparation are explained separately, so those readiness warnings do not hide your navigation. Instrument values depend on current data from Signal K.

## Clear a blocked Wake Logger route

If a leftover or malformed route occupies the location needed by Wake Logger, **Activate** now offers an explicit replacement, naming the route where possible. Automatic course delivery still protects routes belonging to other apps. Conflicts explain which resource is blocking activation. Advancing the native course still requires successful activation.

## Upgrade

Update Wake Logger from the Signal K App Store and restart Signal K if prompted. Your settings and recorded trips are retained. If activation is blocked, open the Race tab, choose **Activate** and review the named replacement before confirming.

This remains a beta release. Offline forecast and chart readiness must still be checked before relying on prepared offline race guidance.
