# Wake Logger for Signal K 0.2.0-beta.13

24 October 2026.

## Clearer sailing guidance

The onboard map now shows port and starboard approaches to the next course mark and an estimated tack or gybe point. Heading and wind filtering reduce small sensor movements, while genuine turns still update promptly. The map keeps its position as readings change, and the persistent guidance information box has been removed.

True wind is shown once as speed and **TWD**, the compass direction the wind comes from. Apparent wind angle remains relative to the bow. Small arrows sit beside the wind readings. Instruments and the Race panel use the same filtered sailing wind as the guidance, preferring water-referenced wind when available and falling back to ground wind when necessary.

## See the effect of leeway

The solid bow line shows the measured compass heading. A separate cyan dashed line shows the estimated course through water after leeway. Current is applied separately to the ground-track laylines, and a separate steering estimate is available when the required inputs support it.

Leeway correction requires a fresh measurement or a validated vessel calibration. Rudder input is optional; a configured model continues without it when supported by the remaining inputs. Missing or stale correction inputs remove the corresponding estimate. No default calibration is invented, and heading minus GPS course is not treated as leeway. Validated vessel polars can supply sailing targets when configured.

## More dependable live tracking

Reconnection now releases an abandoned upload operation so it cannot block the saved-history queue indefinitely. Fresh onboard wind instruments continue working when GPS is unavailable, while position-dependent guidance is withheld. Raw sensor readings and recorded trip data are retained separately from the filtered guidance.

## Upgrade

Update Wake Logger from the Signal K App Store and restart Signal K if prompted, then reload the onboard app. Pairing, settings and recorded trips are retained. Existing instruments continue working without a rudder sensor or leeway calibration; the cyan course line appears only when a valid leeway estimate is available.

Matching live wind and guidance on the Wake Logger website also requires the corresponding website/server update. Older website versions continue receiving the existing telemetry fields.

This remains a beta release.
