# Wake Logger for Signal K 0.2.0-beta.14

Powering on at the berth no longer fills the upload queue with dockside readings. Departure samples stay onboard until movement qualifies as a trip: at least two minutes, 200 metres from the berth reference and positional progress after the first candidate fix. Speed spikes and a single GPS jump do not confirm a trip. Selecting Finish trip also confirms an existing short recording.

## Catch up on real trips

With the matching Wake Logger server update, positively identified old idle history can be retired without uploading its positions. Confirmed trip recordings remain available for uploading; uncertain older recordings stay onboard for review. Idle exclusions, actual uploads and genuine retention loss have separate counters.

Unacknowledged recordings are protected from automatic age-based deletion. If protected history fills the configured storage allowance, the app reports that recording has paused until uploading frees space. Plan enough storage for your offline trip.

## Simpler plugin settings

Optional polar and calibration models no longer appear as required setup fields, and saving ordinary plugin settings no longer creates empty polar errors. Existing calibrated settings and saved device pairing are retained. Live tracking remains controlled in the onboard app.

## Upgrade

Update Wake Logger from the Signal K App Store, restart Signal K if prompted and reload the onboard app. Leave the pairing code blank when the device is already paired. Turn Live tracking on when you want to upload confirmed trips and reconnect the boat to the internet to finish saved uploads.

Retiring an existing idle backlog requires the companion Wake Logger server protocol update. An older server cannot acknowledge idle exclusions; the plugin keeps those declarations pending rather than calling them uploaded. Existing retention loss of legacy diagnostic readings remains separately reported. This update cannot reconstruct race samples that are no longer stored aboard, and a race is only recovered when the cloud confirms its complete history.

This is a beta release. It includes packaged Signal K, broker outage/restart and storage recovery tests; physical-vessel recovery still needs verification aboard.
