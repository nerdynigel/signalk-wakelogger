# Wake Logger 0.2.0-beta.19

When you turn Live tracking back on after a race, Wake Logger spends less time reading the file queue while it uploads the recorded trip. It spaces out retries when the server is slow to confirm a batch. Upload progress still follows the server's durable receipt.

Managed telemetry profiles are saved in arrival order. After reconnecting, the plugin confirms the retained profile again. Switching to a different profile also works when its revision number is lower than the previous profile's.

Update Wake Logger in the Signal K App Store and restart Signal K if prompted. Your existing pairing and recorded trip data carry forward. Upload time depends on the vessel's storage, connection and server response.
