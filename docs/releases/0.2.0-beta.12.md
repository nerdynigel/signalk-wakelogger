# Wake Logger for Signal K 0.2.0-beta.12

22 October 2026.

## Finish the trip when you mean to

Finish trip now asks you to confirm that you want to end the current trip. Further movement starts a new trip card. If you only want to upload saved history while continuing your trip, use Live tracking instead. Cancelling leaves the current trip running, and retrying cloud confirmation does not end it again.

Changing Live tracking continues to control uploading only. Recording continues locally under the same trip identity while Live tracking is off.

## Upload without false sync errors

Uploading saved history or reconnecting no longer produces a false Race Pack acknowledgement error when Wake Logger clears old retained MQTT cache chunks. Cache cleanup preserves the applied course, forecast and existing acknowledgement.

Completed recordings now report whether they ended through Finish trip or the stationary stop rule. This gives the website a durable reason for each trip boundary. Website trip history fixes are a separate server update; this plugin release does not repair existing duplicate cards by itself.

## Upgrade

Update Wake Logger from the Signal K App Store and restart Signal K if prompted. Settings, pairing and recorded trips are retained. Turn Live tracking on in the onboard app when you want to upload saved history. Select Finish trip only when you intend to end the trip.

This remains a beta release.
